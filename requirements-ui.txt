# Runtime dependencies of the Streamlit UI (ui/) only: the Dockerfile installs this for Railway.
# Local development, CI and the agent keep using the full uv project (pyproject.toml + uv.lock);
# this file exists so the image does not pull torch, the CUDA wheels, lightgbm or the agent stack,
# none of which ui/ imports.
#
# Every pin is the version uv.lock holds, and the list is closed: the Dockerfile installs it with
# --no-deps and then runs `pip check`, so a missing package fails the build instead of floating.
# Top level (what ui/ imports): streamlit, streamlit-agraph and pyvis (graph page renderers),
# pandas, python-dotenv, and pyTigerGraph (live mode only, ~3 MB). The rest is their closure for
# Linux / CPython 3.12. After uv.lock changes, regenerate from the repo root with:
#
#   uv export --frozen --no-hashes --no-dev --no-emit-project > /tmp/uv-lock.txt
#   printf 'streamlit\nstreamlit-agraph\npyvis\npandas\npython-dotenv\npyTigerGraph\n' \
#     | uv pip compile - -c /tmp/uv-lock.txt --python-version 3.12 \
#       --python-platform x86_64-manylinux_2_28 --no-annotate --no-header
#
